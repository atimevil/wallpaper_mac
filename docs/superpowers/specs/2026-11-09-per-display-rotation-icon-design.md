# Wallflow: 화면별 배경 · 자동 바꾸기 · 앱 아이콘

작성 2026-11-09 · 상태: 설계 · 브랜치 `feat/local-video-and-desktop-extras`에 이어서

## 왜

dynamicwallpaper 대체 4기능을 끝낸 뒤 남은 차이(사용자 요청 "전부 진행"):
화면마다 다른 배경을 못 걸고, 정해 둔 시간마다 배경을 바꾸지 못하며, 앱 아이콘이 없다
(삭제 확인창에 빈 아이콘이 뜨는 것을 실물에서 봤다). 리뷰에서 남긴 결함 하나(마지막 배경을
지우면 지운 영상이 화면에 남음)도 같이 고친다.

## 범위

1. **화면마다 다른 배경** — 모니터가 둘 이상일 때 화면을 골라 배경을 건다. 재시작·모니터
   재연결 뒤에도 화면마다 기억한다.
2. **자동으로 바꾸기** — 정해 둔 간격마다 다음 배경으로 바꾼다. 순서대로/무작위, 배경마다
   "자동 바꾸기에서 빼기".
3. **앱 아이콘** — 사람 손이 닿은 재료(퍼블릭 도메인 명화)로 만든 아이콘 시안 2~3개, 하나를 기본으로.
4. **결함** — 지운 로컬 영상이 걸린 화면은 남은 배경으로 바꾸고, 남은 게 없으면 그 화면을 비운다.

## 범위 밖

- WE식 "재생 목록 편집 창"(여러 목록 만들기·순서 끌어 바꾸기) — 메뉴 체크 하나("빼기")로 대신한다.
- 시간대별 배경(아침/밤) — 요청 없음.
- 푸시·GitHub 릴리스 — main 병합까지만. 배포는 따로 승인받는다.
- 실패 조건: 한 화면 사용자의 지금 동작이 바뀌면 실패(메뉴·저장 형식 포함). 기존 테스트 회귀 실패.

## 제약

- `WallflowKit`은 AppKit·Metal·AVFoundation을 안 쓴다 → 순수 로직(저장 모델, 다음 배경 고르기)은
  Kit에 두고 테스트, 화면 열거·메뉴·타이머는 App.
- 기존 저장 키 `wallflow.lastSelectedID`는 그대로 "모든 화면" 배경으로 쓴다(하위호환).
- 화면 식별자 `CGDirectDisplayID`는 재연결·재부팅 때 바뀔 수 있다 → 저장은
  `CGDisplayCreateUUIDFromDisplayID` 문자열로 한다.

## 설계

### 1. 화면마다 다른 배경

**Kit `DisplaySelection`(순수, 테스트):** `[화면UUID: 배경id]` 사전 위에서
- `itemID(forDisplay:in:default:)` — 화면별 지정이 있으면 그것, 없으면 기본(모든 화면) 배경.
- `settingAll(_ id, in:)` — "모든 화면"에 걸면 **화면별 지정을 전부 지운다**(정말 모든 화면이 같아야 한다).
- `setting(_ id, forDisplay:in:)` — 그 화면만 바꾼다.
- `removing(itemID:in:)` — 지운 배경을 가리키는 지정을 뺀다.

**App:**
- `DisplaySelectionStore`(UserDefaults `wallflow.selectionByDisplay`).
- `DisplayManager`에 화면 목록(`[(id, uuid, 이름)]`)과 "새로 붙은 화면에 걸 배경" 조회 클로저를
  준다. 재구성 때 `assignments[id] ?? 저장된 화면별 지정 ?? defaultItem` 순서로 고른다.
- 메뉴: 화면이 **둘 이상일 때만** "적용할 화면" 하위 메뉴(모든 화면 / 화면 이름들, 하나만 체크).
  목록에서 배경을 고르면 그 대상에 건다. 한 화면이면 메뉴가 지금과 똑같다.
- "지금 배경"(소리 크기·화면 맞춤·로컬 영상 삭제·설정 창 속성의 기준)은 고른 대상의 배경.
  "모든 화면"이면 기본 배경.
- 대상 선택 자체는 저장하지 않는다(재시작하면 "모든 화면").
- 복원: 기본 배경을 모든 화면에 건 뒤 화면별 지정을 덮는다.

### 2. 자동으로 바꾸기

**Kit `WallpaperRotation.next(after:in:shuffle:random:)`(순수, 테스트):** 후보 id 목록에서
순서대로면 다음(끝이면 처음), 무작위면 지금 것과 다른 것 하나. 후보가 없거나 지금 것뿐이면 nil.
`random`을 주입해 테스트한다.

**후보:** 열 수 있는 라이브러리 항목(`.unsupported` 제외) 중 "빼기"하지 않은 것.
빼기 목록은 `wallflow.rotationExcluded`(id 배열).

**App `RotationController`:** 간격(끔/5분/15분/30분/1시간/하루, 기본 끔)마다 한 번.
- 화면별 지정이 없으면 기본 배경을 다음으로 바꿔 모든 화면에 건다(화면끼리 맞춰 바뀐다).
- 화면별 지정이 있으면 화면마다 자기 배경의 다음으로 바꾼다.
- **전력 정책이 멈춤일 때(가려짐·자리 비움·전체화면 앱) 차례가 오면 바로 바꾸지 않고 "밀림"으로
  두었다가, 다시 그리기 시작할 때 바꾼다** — 아무도 안 보는 동안 씬을 새로 읽느라 전력을 쓰지 않는다.
- 사용자가 직접 배경을 고르면 타이머를 처음부터 다시 센다.

**메뉴:** "자동으로 바꾸기" 하위 메뉴 — 간격(하나만 체크), 구분선, "무작위 순서" 체크,
"이 배경은 빼기" 체크(지금 배경 기준).

### 3. 앱 아이콘

메모리 규칙(`design-no-ai-look`): 직접 그린 기하 도형·이모지 금지, 사람 손이 닿은 재료부터,
시안은 한 번에 2~3개. 재료는 미술관 공개(퍼블릭 도메인) 명화에서 "흐름·움직임"이 보이는
부분을 잘라 쓴다 — 후보: 호쿠사이 「가나가와 해변의 높은 파도」, 반 고흐 「별이 빛나는 밤」,
모네 「수련」. 출처·라이선스를 저장소에 남긴다(`Resources/AppIcon-SOURCE.md`).
`bundle.sh`가 `.icns`를 `Contents/Resources`에 넣고 `CFBundleIconFile`을 적는다. 메뉴바 아이콘은
지금처럼 SF Symbol.

### 4. 지운 배경이 남는 결함

`deleteLocalVideo`가 지운 id를 가리키던 **모든 화면**을 찾아, 남은 열 수 있는 배경이 있으면 그걸로,
없으면 그 화면의 렌더러를 멈추고 배경 창을 내린다(macOS 기본 바탕화면이 보임). 화면별 지정·
자동 바꾸기 빼기 목록·배경별 볼륨에서도 지운 id를 뺀다. 배경을 다시 걸면 창을 다시 올린다.

## 레드팀 반영(구현 전, 이 절이 위 내용보다 우선)

1. **속성 편집이 모든 화면을 덮어쓰던 경로 제거.** `reloadCurrent()`(기본 배경을 모든 화면에 다시 검)를
   없애고 `reload(itemID:)` — 그 배경이 걸린 화면만 다시 연다. `PropertyEditorView.onChanged`가 편집 중인
   배경 id를 넘긴다(설정 창·창작마당 창 둘 다).
2. **"적용 대상"은 `AppCoordinator`가 하나만 들고**, 메뉴와 창작마당 창의 "적용"이 모두 그걸 쓴다.
   "지금 배경"(메뉴·설정 창·창작마당 강조)은 대상의 배경. 창작마당의 "지금 쓰는 중" 삭제 경고는
   **어느 화면에든 걸려 있으면** 뜬다(`isItemInUse` 추가).
3. **지운 배경 처리는 한 곳에서.** `refreshLibrary()`가 스캔 결과에 없는 배정(기본 배경 포함)을 찾아
   처리한다 — 메뉴 삭제·창작마당 삭제 둘 다 덮는다. 남은 배경이 있으면 바꿔 걸고, 없으면 렌더러를 멈추고
   창을 내리며 `defaultItem`·`lastSelectedID`도 비운다(새로 꽂은 모니터에 지운 배경이 걸리지 않게).
   감상 모드는 **보이는 창만** 올린다(내린 창이 검게 올라오지 않게).
4. **자동 바꾸기 시각은 저장한다.** `wallflow.rotationLastDate`를 두고 `지금 - 마지막 ≥ 간격`이면 바꾼다.
   확인 주기는 `min(60초, 간격/4)`. 잠자기·재시작을 넘겨도 "하루"가 지켜진다. 사용자가 직접 고르면 시각을
   지금으로 다시 잡는다.
5. **멈춤 중 미루기 없음.** 제때 바꾼다(`attach`가 멈춤 상태를 그대로 적용하므로 멈춘 채 읽힌다). 화면이
   잠들어 있을 때(`CGDisplayIsAsleep`)만 건너뛴다.
6. **후보 제외:** `.unsupported`와 변환이 안 되는 영상(`conversionState`가 ffmpeg 없음·실패).
7. **화면 키:** UUID가 겹치는 화면끼리는 `UUID#순번`으로 구별한다(같은 모델 두 대).
8. **대상을 메뉴 제목에 보인다:** "적용할 화면: 화면 2". 대상을 바꾸면 설정 창 속성도 다시 채운다.
9. **"모든 화면"은 지금 연결된 화면의 지정만 지운다** — 꺼져 있는 모니터(회사 모니터 등) 설정은 남는다.
10. 아이콘은 메트 미술관 CC0만 쓴다(모네 수련은 메트 자료가 퍼블릭 도메인이 아니라 제외, 히로시게
    「나루토 소용돌이」 53783을 기본). 16/32/128px로 줄여 비교했고 모서리는 투명. `bundle.sh`만 고치면
    `dist.sh`도 따라간다.
11. 장시간: 자동 바꾸기를 짧은 간격으로 여러 번 돌려 메모리(RSS)와 임시 파일이 늘지 않는지 본다.
12. 범위 밖으로 남김(기존 동작): 같은 씬을 두 화면에 걸면 소리가 화면마다 나는 것, 전체화면 앱 판정이
    주 화면만 보는 것.

## 코드 리뷰·실물 시험에서 고친 것

- **지운 배경 판정:** 스캔에서 빠졌다고 지운 게 아니다(수정 중·링크 대상 잠깐 없음). 라이브러리 항목
  (폴더·링크) 자체가 없어졌을 때만 정리한다(`attributesOfItem`은 링크를 따라가지 않는다).
- **지운 배경 대신 걸 것:** 살아 있으면 "모든 화면" 배경 — 화면별 지정을 지우므로 재시작 뒤와 같다.
- **일부 화면만 따로일 때 자동으로 바꾸기:** 지정 없는 화면은 "모든 화면" 배경을 같이 넘긴다(지정을
  새로 만들지 않는다 — 기본이 굳지 않게).
- **같은 UUID 순번**은 화면 위치 순서로 매긴다(메뉴바를 옮겨도 설정이 안 바뀐다).
- **모니터를 꽂거나 빼면 메뉴를 다시 만든다**(뺀 뒤에도 "적용할 화면"이 남아 있던 것을 실물에서 발견).
- **복원은 화면마다 처음부터 자기 배경**을 건다(기본을 다 걸었다 바꾸느라 씬을 두 번 읽던 것).
- **새로 꽂은 화면은 걸 배경이 있을 때만 창을 올린다**(빈 검은 창 방지).
- **감상 모드: 화면 유지 유틸리티는 세지 않는다.** Vorssaint·caffeinate·Amphetamine·KeepingYouAwake·
  Theine·Caffeine·Lungo의 "화면 켜 두기"는 영상 재생이 아니다 — 세면 이런 앱을 상시 쓰는 사람(실측:
  이 맥의 Vorssaint)에겐 감상 모드가 영영 안 뜬다. 목록에 없는 유틸리티는 macOS 화면보호기처럼 비켜 준다.
- 앱이 켜질 때 이미 간격이 지났으면(로그인 항목) 첫 확인 주기 안에 바꾼다 — 의도대로.

## 실물 확인(2026-11-09, macOS 26, 내장 1728×1117 + 가상 디스플레이 1920×1080)

가상 디스플레이는 CoreGraphics의 비공개 `CGVirtualDisplay`로 만들었다(같은 설정이면 UUID가 같아 재연결 시험이 됨).
- 화면별: 대상을 고르면 메뉴 제목이 바뀌고, 그 화면에만 걸리고 UUID로 저장됨. 체크 표시가 대상을 따라감.
  재시작 뒤 화면마다 복원. 화면을 뺐다 꽂으면(번호 7→8) 그 화면 배경이 돌아옴. 뺀 채로 "모든 화면"을
  고르면 뺀 화면 설정은 남고, 꽂힌 채로 고르면 지워짐. 한 화면이면 "적용할 화면" 메뉴가 없다.
- 자동으로 바꾸기: 순서대로 돌고 처음으로 돌아옴. 빼기 둘은 한 번도 안 나옴. 무작위는 같은 것 연속 없음.
  일부 화면만 따로일 때 각자 돌고 기본 화면엔 지정이 안 생김. 메뉴로 15분·빼기·끔이 저장·제목에 반영.
  6초 간격으로 22번 바꾸는 동안(약 2.5분) 메모리는 배경에 따라 1.06~1.8GB를 오갔고 늘어나는 추세 없음,
  임시 영상 파일 0개.
- 지운 배경: 시험 화면에만 건 로컬 영상을 지우니 그 화면은 "모든 화면" 배경으로, 화면별 저장은 지워짐.
- 감상 모드: Vorssaint가 화면을 켜 두는 중에도 유휴 78초에 두 화면 모두 레이어 1000으로 올라가고, 입력
  283ms 뒤 둘 다 내려감.
- 아이콘: Finder(Launch Services)가 보여 주는 아이콘이 소용돌이로 나옴, 서명 유효.
- 확인 못 한 것: 실제 물리 모니터 두 대(같은 모델 UUID 겹침 포함), 배경을 전부 지운 뒤 상태(사용자
  라이브러리를 비울 수 없어서), 설정 창 속성 편집이 그 화면만 다시 여는 것(코드 리뷰로만 확인).

## 검증 계획

- Kit 단위 테스트: `DisplaySelection`, `WallpaperRotation`.
- 실물: 모니터가 하나뿐이라 **가상 디스플레이**(CoreGraphics `CGVirtualDisplay`)를 만들어 두 화면에서
  화면별 배경·재연결 복원을 확인한다. 만들 수 없으면 "두 화면 미검증"으로 보고한다.
- 자동 바꾸기는 간격을 시험용으로 짧게(저장값만) 두고 순서대로·무작위·빼기·멈춤 중 밀림을 확인.
- 아이콘은 Finder·확인창에서 눈으로 확인.

## 순서

결함(4) → 화면별(1) → 자동 바꾸기(2) → 아이콘(3). 기능별 커밋, 커밋에 Claude 서명·모델 언급 없음.
설계 레드팀 1회, 구현 후 코드 리뷰 1회, 실물 시험 후 main 병합(로컬). 푸시·릴리스는 별도 승인.
