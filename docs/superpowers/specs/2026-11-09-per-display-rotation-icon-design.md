# Wallflow: 화면별 배경 · 자동 바꾸기 · 앱 아이콘

작성 2026-11-09 · 상태: 설계 · 브랜치 `feat/local-video-and-desktop-extras`에 이어서

## 왜

dynamicwallpaper 대체 4기능을 끝낸 뒤 남은 차이(사용자 요청 "전부 진행"):
화면마다 다른 배경을 못 걸고, 정해 둔 시간마다 배경을 바꾸지 못하며, 앱 아이콘이 없다
(삭제 확인창에 빈 아이콘이 뜨는 것을 실물에서 봤다). 리뷰에서 남긴 결함 하나(마지막 배경을
지우면 지운 영상이 화면에 남음)도 같이 고친다.

## 범위

1. **화면마다 다른 배경** — 모니터가 둘 이상일 때 화면을 골라 배경을 건다. 재시작·모니터
   재연결 뒤에도 화면마다 기억한다.
2. **자동으로 바꾸기** — 정해 둔 간격마다 다음 배경으로 바꾼다. 순서대로/무작위, 배경마다
   "자동 바꾸기에서 빼기".
3. **앱 아이콘** — 사람 손이 닿은 재료(퍼블릭 도메인 명화)로 만든 아이콘 시안 2~3개, 하나를 기본으로.
4. **결함** — 지운 로컬 영상이 걸린 화면은 남은 배경으로 바꾸고, 남은 게 없으면 그 화면을 비운다.

## 범위 밖

- WE식 "재생 목록 편집 창"(여러 목록 만들기·순서 끌어 바꾸기) — 메뉴 체크 하나("빼기")로 대신한다.
- 시간대별 배경(아침/밤) — 요청 없음.
- 푸시·GitHub 릴리스 — main 병합까지만. 배포는 따로 승인받는다.
- 실패 조건: 한 화면 사용자의 지금 동작이 바뀌면 실패(메뉴·저장 형식 포함). 기존 테스트 회귀 실패.

## 제약

- `WallflowKit`은 AppKit·Metal·AVFoundation을 안 쓴다 → 순수 로직(저장 모델, 다음 배경 고르기)은
  Kit에 두고 테스트, 화면 열거·메뉴·타이머는 App.
- 기존 저장 키 `wallflow.lastSelectedID`는 그대로 "모든 화면" 배경으로 쓴다(하위호환).
- 화면 식별자 `CGDirectDisplayID`는 재연결·재부팅 때 바뀔 수 있다 → 저장은
  `CGDisplayCreateUUIDFromDisplayID` 문자열로 한다.

## 설계

### 1. 화면마다 다른 배경

**Kit `DisplaySelection`(순수, 테스트):** `[화면UUID: 배경id]` 사전 위에서
- `itemID(forDisplay:in:default:)` — 화면별 지정이 있으면 그것, 없으면 기본(모든 화면) 배경.
- `settingAll(_ id, in:)` — "모든 화면"에 걸면 **화면별 지정을 전부 지운다**(정말 모든 화면이 같아야 한다).
- `setting(_ id, forDisplay:in:)` — 그 화면만 바꾼다.
- `removing(itemID:in:)` — 지운 배경을 가리키는 지정을 뺀다.

**App:**
- `DisplaySelectionStore`(UserDefaults `wallflow.selectionByDisplay`).
- `DisplayManager`에 화면 목록(`[(id, uuid, 이름)]`)과 "새로 붙은 화면에 걸 배경" 조회 클로저를
  준다. 재구성 때 `assignments[id] ?? 저장된 화면별 지정 ?? defaultItem` 순서로 고른다.
- 메뉴: 화면이 **둘 이상일 때만** "적용할 화면" 하위 메뉴(모든 화면 / 화면 이름들, 하나만 체크).
  목록에서 배경을 고르면 그 대상에 건다. 한 화면이면 메뉴가 지금과 똑같다.
- "지금 배경"(소리 크기·화면 맞춤·로컬 영상 삭제·설정 창 속성의 기준)은 고른 대상의 배경.
  "모든 화면"이면 기본 배경.
- 대상 선택 자체는 저장하지 않는다(재시작하면 "모든 화면").
- 복원: 기본 배경을 모든 화면에 건 뒤 화면별 지정을 덮는다.

### 2. 자동으로 바꾸기

**Kit `WallpaperRotation.next(after:in:shuffle:random:)`(순수, 테스트):** 후보 id 목록에서
순서대로면 다음(끝이면 처음), 무작위면 지금 것과 다른 것 하나. 후보가 없거나 지금 것뿐이면 nil.
`random`을 주입해 테스트한다.

**후보:** 열 수 있는 라이브러리 항목(`.unsupported` 제외) 중 "빼기"하지 않은 것.
빼기 목록은 `wallflow.rotationExcluded`(id 배열).

**App `RotationController`:** 간격(끔/5분/15분/30분/1시간/하루, 기본 끔)마다 한 번.
- 화면별 지정이 없으면 기본 배경을 다음으로 바꿔 모든 화면에 건다(화면끼리 맞춰 바뀐다).
- 화면별 지정이 있으면 화면마다 자기 배경의 다음으로 바꾼다.
- **전력 정책이 멈춤일 때(가려짐·자리 비움·전체화면 앱) 차례가 오면 바로 바꾸지 않고 "밀림"으로
  두었다가, 다시 그리기 시작할 때 바꾼다** — 아무도 안 보는 동안 씬을 새로 읽느라 전력을 쓰지 않는다.
- 사용자가 직접 배경을 고르면 타이머를 처음부터 다시 센다.

**메뉴:** "자동으로 바꾸기" 하위 메뉴 — 간격(하나만 체크), 구분선, "무작위 순서" 체크,
"이 배경은 빼기" 체크(지금 배경 기준).

### 3. 앱 아이콘

메모리 규칙(`design-no-ai-look`): 직접 그린 기하 도형·이모지 금지, 사람 손이 닿은 재료부터,
시안은 한 번에 2~3개. 재료는 미술관 공개(퍼블릭 도메인) 명화에서 "흐름·움직임"이 보이는
부분을 잘라 쓴다 — 후보: 호쿠사이 「가나가와 해변의 높은 파도」, 반 고흐 「별이 빛나는 밤」,
모네 「수련」. 출처·라이선스를 저장소에 남긴다(`Resources/AppIcon-SOURCE.md`).
`bundle.sh`가 `.icns`를 `Contents/Resources`에 넣고 `CFBundleIconFile`을 적는다. 메뉴바 아이콘은
지금처럼 SF Symbol.

### 4. 지운 배경이 남는 결함

`deleteLocalVideo`가 지운 id를 가리키던 **모든 화면**을 찾아, 남은 열 수 있는 배경이 있으면 그걸로,
없으면 그 화면의 렌더러를 멈추고 배경 창을 내린다(macOS 기본 바탕화면이 보임). 화면별 지정·
자동 바꾸기 빼기 목록·배경별 볼륨에서도 지운 id를 뺀다. 배경을 다시 걸면 창을 다시 올린다.

## 검증 계획

- Kit 단위 테스트: `DisplaySelection`, `WallpaperRotation`.
- 실물: 모니터가 하나뿐이라 **가상 디스플레이**(CoreGraphics `CGVirtualDisplay`)를 만들어 두 화면에서
  화면별 배경·재연결 복원을 확인한다. 만들 수 없으면 "두 화면 미검증"으로 보고한다.
- 자동 바꾸기는 간격을 시험용으로 짧게(저장값만) 두고 순서대로·무작위·빼기·멈춤 중 밀림을 확인.
- 아이콘은 Finder·확인창에서 눈으로 확인.

## 순서

결함(4) → 화면별(1) → 자동 바꾸기(2) → 아이콘(3). 기능별 커밋, 커밋에 Claude 서명·모델 언급 없음.
설계 레드팀 1회, 구현 후 코드 리뷰 1회, 실물 시험 후 main 병합(로컬). 푸시·릴리스는 별도 승인.
