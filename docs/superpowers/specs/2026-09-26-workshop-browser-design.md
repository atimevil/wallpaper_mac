# 창작마당 창 — Wallpaper Engine 브라우저처럼

날짜: 2026-09-26 · 상태: 설계(사용자 요구 확정, 목표 "알아서 진행"에 따라 추천안으로 진행)

## 목표

WE 창작마당 브라우저와 같은 화면·동작으로 고른다. 사용자가 말한 네 가지를 모두 푼다:
고르기 전에 정보가 부족함, 필터·태그가 불편함, 둘러보는 맛이 없음, WE 화면 그대로.
추가 요구: **더블클릭** — 창작마당 탭은 받기, 설치된 탭은 배경화면 적용.
설치된 탭의 오른쪽 패널에서 **속성을 바로 바꾼다**(바꾸면 즉시 적용).

지키는 것: Steam 계정 자격 증명은 다루지 않는다(받기는 지금처럼 steamcmd 캐시 로그인).
목록·정보는 로그인 없는 공개 페이지·공개 API만 쓴다.

## 지금

`Sources/WallflowApp/WorkshopWindowController.swift`(972줄): 탭(창작마당/라이브러리), 격자
(`NSCollectionView`, 정지 썸네일), 검색, 정렬 팝업, 종류·장르·해상도·등급 팝업, 특성 체크박스
(승인됨·오디오 응답성·커스텀 가능 등), 받은 것 숨기기, 이전/다음 페이지, 받기·지우기·적용 버튼,
계정 입력. 속성 편집은 `SettingsWindowController`의 속성 탭에 따로 있다.

## 화면

세 칸 `NSSplitView`. 창 기본 크기 1280×800, 최소 980×600.

1. **왼쪽 사이드바(폭 220, 접을 수 있음)** — WE의 필터 목록.
   - 탭 전환(창작마당 / 설치됨)은 창 위쪽 세그먼트로 유지.
   - 섹션: 종류(씬·비디오·웹), 연령 등급(전체·선정성·성인), 해상도, 장르 태그(24개), 기타
     (승인됨·오디오 응답성·커스텀 가능·미디어 연동). 전부 **체크박스**, 여러 개 선택.
   - 같은 섹션 안에서 여러 개를 고르면: 종류·등급·해상도는 "그중 하나"(OR), 장르·기타는
     "모두"(AND, Steam `requiredtags[]` 그대로). OR는 Steam 목록 요청이 지원하지 않으므로
     종류·등급·해상도에서 둘 이상 고르면 해당 섹션 필터를 요청에서 빼고 받아 온 결과를
     클라이언트에서 거른다(`WorkshopItem.tags`로 판정). 한 개만 고르면 요청에 넣는다.
   - "초기화" 버튼, 받은 것 숨기기 체크박스.
   - 설치됨 탭에서도 같은 사이드바로 로컬 목록을 거른다(종류·태그는 project.json 기준).
2. **가운데 격자**
   - 위쪽 줄: 검색창, 정렬(기존 8종), 격자 크기 슬라이더(작게/크게 — 칸 폭 160~320).
   - 칸: 정사각 미리보기 + 아래 제목 한 줄(말줄임). 받은 항목엔 오른쪽 위 체크 배지, 받는 중엔
     진행 막대.
   - **마우스를 올리면** 미리보기가 GIF면 그 칸만 움직인다(나머지는 첫 장). 벗어나면 멈춘다.
   - **무한 스크롤**: 끝에서 두 줄 앞에 닿으면 다음 페이지를 받아 이어 붙인다. 이전/다음 버튼은
     없앤다. 같은 항목이 다음 페이지에 또 오면 뺀다(Steam 목록이 요청 사이에 바뀜).
   - 선택: 한 번 누르면 오른쪽 패널 갱신, **더블클릭**은 받기(창작마당) / 적용(설치됨).
     이미 받은 항목을 창작마당 탭에서 더블클릭하면 적용한다.
3. **오른쪽 상세 패널(폭 340)**
   - 공통: 큰 미리보기(GIF면 움직임), 제목, 작성자, 평점(별 5개, 반 별 포함)과 평가 수, 구독자
     수, 파일 크기, 올린 날·고친 날, 태그 칩, 설명(스크롤, Steam BB코드는 평문으로 — 굵게/링크만
     살림).
   - 창작마당 탭: "받기" 버튼(받은 것이면 "적용"), 받는 중엔 진행률. "Steam에서 열기" 링크.
   - 설치됨 탭: "적용", "지우기" 버튼, 그 아래 **속성 편집기** — 설정 창의 속성 탭과 같은
     컨트롤(색·체크·슬라이더·콤보·글자·폴더/파일), 조건부 표시(`UserProperty.isVisible`) 그대로,
     바꾸면 저장하고 그 배경화면이 걸린 화면에 즉시 적용.

## 데이터

- 목록 ID: 지금처럼 browse HTML에서 `filedetails/?id=` 추출(`WorkshopClient.parseIDs`).
- 칸·패널 기본 정보: `ISteamRemoteStorage/GetPublishedFileDetails`(키 없음) — 제목, 설명,
  파일 크기, 미리보기 URL, 태그, 구독자(`subscriptions`, `lifetime_subscriptions`),
  즐겨찾기, 조회수, `time_created`, `time_updated`, `creator`. `WorkshopItem`에 필요한 필드를
  더한다.
- 평점·작성자 이름: 키 없는 API에 없다. 항목을 **고를 때만** 상세 페이지
  (`sharedfiles/filedetails/?id=`) HTML을 받아 `fileRatingDetails`의 `N-star_large.png`
  (0~5, 반 별은 `N_half`가 있으면), `numRatings`의 "N ratings", `friendBlockContent`의 작성자
  이름을 뽑는다. 못 뽑으면 그 칸만 비운다(오류로 막지 않음). 결과는 메모리에 캐시.
- 썸네일: 칸용은 `preview_url`에 크기 파라미터(`?imw=…`)를 붙여 작게, GIF 여부는 받은 데이터
  첫 바이트로 판단. 이미지 캐시는 개수 상한(예: 600개) LRU.

## 구조

- Kit(순수·테스트): 필터 모델(`WorkshopFilterState` — 섹션별 선택 → 요청 태그 + 클라이언트
  필터 판정), 상세 HTML 해석(`WorkshopDetailsPage.parse(html:) -> (rating, ratingCount, author)`),
  BB코드 → 평문 변환, 무한 스크롤 페이지 병합(중복 제거), 상세 필드 확장 파싱.
- App: `WorkshopWindowController`를 세 칸으로 다시 구성하되 받기/지우기/적용/로그인 흐름은
  재사용. 사이드바(`WorkshopSidebarView`), 격자 칸(`WorkshopGridItem` 확장: 호버 GIF·배지·진행),
  상세 패널(`WorkshopDetailPanel`), 속성 편집기는 `SettingsWindowController`의 행 생성 코드를
  `PropertyEditorView`로 떼어 설정 창과 상세 패널이 같이 쓴다.

## 오류·경계

- 네트워크 실패: 격자 아래에 한 줄 안내와 "다시 시도"; 이미 받은 줄은 유지.
- 상세 페이지 해석 실패: 평점·작성자만 비움.
- 받기 실패(로그인 캐시 없음 등): 지금 흐름 그대로(로그인 안내).
- 성인 태그는 사용자가 등급 필터에서 고를 때만 보인다(기본은 전체 이용가만 — 지금 기본과 같게).

## 테스트

Kit 단위: 필터 → 요청 쿼리·클라이언트 판정, 상세 HTML 해석(실제 페이지 스냅숏 고정 파일),
BB코드 변환, 페이지 병합 중복 제거, 확장 필드 파싱. 화면은 메인 세션이 앱을 띄워 찍어 확인
(창작마당 탭 둘러보기·필터·호버·상세·더블클릭 받기, 설치됨 탭 속성 변경 즉시 반영).

## 하지 않는 것

로그인이 필요한 기능(구독 목록 동기화, 평가하기, 댓글), 컬렉션 탐색, 작성자 페이지 탐색.
